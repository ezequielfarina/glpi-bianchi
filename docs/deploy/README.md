
## Etiqueta de envio (impressora térmica Argox)

A etiqueta sai direto na Argox pela rede: configure IP, porta (9100), linguagem (PPLB ou PPLZ) e tamanho em
*Configurações → Impressora de etiquetas* e use **Imprimir etiqueta de teste**. O CT precisa alcançar `IP:9100`
(regra no FortiGate se houver). Passo a passo, testes com `nc` e troubleshooting:
[docs/stock/estoque-e-notas.md](../stock/estoque-e-notas.md#impressão-na-argox).
